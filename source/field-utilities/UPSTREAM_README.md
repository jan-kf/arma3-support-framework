[h1]Pontifex: Field Utilities[/h1]

Field Utilities is a toolbox of engineering, logistics, and support workflows for improvised battlefield problem solving. It combines construction tools, fabrication systems, supply handling, and field-expedient drone options into one shared utility package.

[h2]Included Systems[/h2]
[list]
[*]Fabricator and Virtual Storage modules for spawning synced assets and equipment from designated fabrication points
[*]Fabricator UI with configurable monochrome styling and optional local virtual inventory support
[*]Bridge Builder workflow with a dedicated construction box, planning UI, preview rendering, ramp mode, and removal tools
[*]Logistics actions for handling pallets, containers, vehicles, and supply movement
[*]Vehicle towing and rope management utilities
[*]FPV drone field actions for attaching IEDs, mortar rounds, or grenades
[/list]

[h2]Mission Maker Setup[/h2]
[list]
[*]Use the Virtual Storage module to define what assets and items can be reproduced by fabricators.
[*]Use the Fabricator module to designate the objects that will open the fabrication interface.
[*]The Bridge Construction Box can be placed directly in the editor and opened through ACE interactions.
[*]Many logistics and towing actions are attached automatically to supported vehicles and supply objects.
[/list]

[h2]Notes[/h2]
[list]
[*]Requires CBA_A3, CORDIS, ACE, and ZEN.
[*]This beta build is intended for testing, so placement rules, UI behavior, and utility workflows may change between versions.
[/list]
