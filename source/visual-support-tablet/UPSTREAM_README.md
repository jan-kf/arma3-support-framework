[h1]Pontifex: V.I.G.I.L.[/h1]

[i]Virtual Interfaced Governor for Integrated Logistics[/i]

VIGIL is a battlefield command tablet for coordinating support assets from a single interface. It gives players a unified way to task friendly transport, close air support, artillery, and fixed-wing assets without relying on bespoke mission scripts for every request.

[h2]Core Features[/h2]
[list]
[*]Unified support tablet for rotary transport, CAS, artillery, and fixed-wing tasking
[*]Live asset browsing with status details for supported units in the area of operations
[*]Artillery fire missions with shell selection, spread, count, and strike pattern controls
[*]Dynamic fixed-wing deployment, RTB control, and laser-guided bomb or missile requests
[*]Mission maker asset whitelisting with Zeus tools for live add or remove control
[*]CBA settings for tablet requirement, radio or side message behavior, colors, and keybinds
[/list]

[h2]How To Use[/h2]
[list]
[*]By default, equip a VIGIL tablet in the GPS slot and press [b]Ctrl + Home[/b] to open the interface.
[*]The tablet requirement and keybind can both be changed in Addon Options.
[*]Friendly manned assets on the player's side can populate the tablet automatically, or mission makers can restrict the list with the Asset Whitelist module.
[*]Fixed-wing workflows use dedicated Eden and Zeus modules to register aircraft and define deployment points.
[/list]

[h2]Notes[/h2]
[list]
[*]Requires CBA_A3 and CORDIS.
[*]This beta build is intended for testing and iteration, so UI flow, balance, and supported tasking behavior may change between versions.
[/list]
